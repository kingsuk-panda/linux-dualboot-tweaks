# Contributing

1. Fork the repo and create a feature branch.
2. Keep each feature in its own folder with its own README.md, the actual
   config/script/theme files, and a Bundled-files section explaining exact
   install paths.
3. Test on at least one distro (Arch, Ubuntu, or Fedora) and note that in the PR.
4. Do not commit personal secrets, SSH keys, or private keys.
5. Open a PR with a short description of what you added/changed and how you tested.
